# Step 002 — Frontend: move placeholder components to shared folder

## Goal

Relocate the four placeholder UI files from
`frontend/src/admin/components/pipelines/` to a new shared admin
folder `frontend/src/admin/components/placeholders/`, and update
all import sites. Pure refactor — no behavior change.

- `frontend/src/admin/components/pipelines/PlaceholderTextarea.tsx`
  → `frontend/src/admin/components/placeholders/PlaceholderTextarea.tsx`
- `frontend/src/admin/components/pipelines/PlaceholderPanel.tsx`
  → `frontend/src/admin/components/placeholders/PlaceholderPanel.tsx`
- `frontend/src/admin/components/pipelines/PlaceholderSuggestions.tsx`
  → `frontend/src/admin/components/placeholders/PlaceholderSuggestions.tsx`
- `frontend/src/admin/components/pipelines/placeholderAutocompleteState.ts`
  → `frontend/src/admin/components/placeholders/placeholderAutocompleteState.ts`

Modify (update imports):

  `from '../components/pipelines/Placeholder...'` with
  `from '../components/placeholders/Placeholder...'`. The known
  call sites are around lines ~near top (imports), ~43, and
  ~69-178; coder updates all of them.

Optionally modify (only if found by grep):
