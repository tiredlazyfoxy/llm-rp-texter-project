# Step 007 — Frontend: wire placeholder UI into DocumentEditPage

## Goal

Add the same placeholder UX (clickable badge panel + `{PARTIAL`
autocomplete) to the `Content` field on `DocumentEditPage` that
`WorldFieldEditPage` already has for `initial_message`. Reuse the
shared `components/placeholders/` trio. Rename the constants module
so the same `PlaceholderInfo[]` is shared by both pages — single
source of truth for the three runtime placeholders.

## Files to create or modify

Rename (preserve history with `git mv`):
- `frontend/src/admin/components/placeholders/initialMessagePlaceholders.ts`
  → `frontend/src/admin/components/placeholders/runtimePlaceholders.ts`
- Inside the renamed file: rename the exported constant
  `INITIAL_MESSAGE_PLACEHOLDERS` → `RUNTIME_PLACEHOLDERS`. Content
  of the array is unchanged (the same three `PlaceholderInfo`
  entries: CHARACTER_NAME, LOCATION_NAME, LOCATION_SUMMARY).

Modify:
- `frontend/src/admin/pages/WorldFieldEditPage.tsx` — update the
  import path to `../components/placeholders/runtimePlaceholders`
  and the imported name to `RUNTIME_PLACEHOLDERS`. All other code
  in this file is unchanged.
- `frontend/src/admin/pages/DocumentEditPage.tsx` — replace the
  `<Textarea label="Content">` block (lines 214-223) with
  `<PlaceholderTextarea>` + `<PlaceholderPanel>`, mirroring the
  pattern in `WorldFieldEditPage`'s `initial_message` branch.
  Add a `useRef<PlaceholderTextareaController | null>(null)` for
  the imperative API. Drop the now-unused `Textarea` import (line
  18) if no other field on the page still uses it; otherwise keep
  it. Leave the `<LlmChatPanel>` block at line 226 untouched.
  The `Name` input and metadata fields are unchanged. Page stays
  wrapped in `observer`.

Read-only references (do not modify):

  `state.draft.content` binding stays the same;
  `PlaceholderTextarea` exposes the same `value` / `onChange`
  contract as the Mantine `Textarea` it replaces.

Tests / build:
- `npx tsc --noEmit` clean.
- `npx vite build` succeeds.
- Adjust any frontend test that imports
  `INITIAL_MESSAGE_PLACEHOLDERS` to use `RUNTIME_PLACEHOLDERS`
