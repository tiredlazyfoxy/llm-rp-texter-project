# Step 006 — Frontend UI: gear blink + panel running-state

## Goal

Wire the retune running-state and blink flag into the UI: blink the settings gear on
finish, and give the settings panel a running affordance (disabled/grayed fields +
spinner + Stop) plus a "Retune now" button when idle.

## Source files

frontend/src/user/pages/ChatViewPage.tsx
frontend/src/user/components/chats/ChatSettingsPanel.tsx

## Test files

_none — frontend has no test runner; the gate is `cd frontend && npx tsc --noEmit`._

## Interface intent

- **`ChatViewPage.tsx`** — wrap the settings gear `ActionIcon` (the
  `<IconSettings size={18}/>` at :88-92) in a Mantine `Indicator` that is shown /
  processing-animated when `state.retuneJustFinished` is true, and dismissed
  otherwise. When the settings panel is opened (`setSettingsOpen(true)`), call
  `clearRetuneBlink(state)` so the blink is consumed on open. `Indicator` must be
  added to the Mantine import (it is NOT imported today; `Badge` already is but is
  used for the archived pill — do not reuse it for this). Keep `observer`.
- **`ChatSettingsPanel.tsx`** — inside the existing tuning block (:204-237, gated by
  `showTuning` = `isEditor` && `isChainMode`, both unchanged):
  - When `state.retuneRunning` is true: render the two tuning textareas as
    disabled/grayed, show a spinner/loader beside the field, and render a **Stop**
    button that calls the step-005 `stopRetune(state)` action. Hide Save/Revert
    while running (they operate on fields that are being recomputed).
  - When idle: render the existing editable textareas + Save (`handleSaveTuning`
    :130-137) + Revert (`handleRevertTuning` :139-141), PLUS a new **"Retune now"**
    button that calls the step-005 `triggerRetuneNow(state)` action.
  - After a retune finishes, the component's local edit buffers (`planTuning` /
    `toneTuning` `useState` at :97-99) must reseed from the refreshed
    `state.tuningProfile` — extend or rely on the existing reseed-from-profile
    `useEffect` (:125-128) so the new values appear once `tuningProfile` updates.
  - Keep the chain-only + editor gating; players and non-chain modes see nothing new.

## Definition of done

1. `[test]` `cd frontend && npx tsc --noEmit` passes with the `Indicator` import, the
   gear wrapper, and the panel running-state branches. (DoD-1)
2. `[test]` `cd frontend && npm run build` succeeds (typecheck + bundle). (DoD-2)
3. `[manual/live]` When a background retune finishes, the gear blinks; opening the
   settings panel clears the blink. (DoD-3)
4. `[manual/live]` While a retune runs, the tuning textareas are disabled/grayed with
   a spinner and a Stop button; clicking Stop halts the job. (DoD-4)
5. `[manual/live]` When idle, a "Retune now" button is present and starts a
   background retune; after it finishes the textareas reseed to the new values. (DoD-5)
6. `[manual/live]` Non-editor users and non-chain modes see no retune UI (gating
   unchanged). (DoD-6)

## Dependencies

005 (page-state observables `retuneRunning` / `retuneJustFinished` and actions
`triggerRetuneNow` / `stopRetune` / `clearRetuneBlink`).
