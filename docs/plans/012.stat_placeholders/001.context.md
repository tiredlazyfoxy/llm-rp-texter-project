## Render rule reminders

- `int` → `str(value)`
- `enum` → value as-is (it is already a string)
- `set` → `", ".join(...)`. Iteration order: prefer the
  `WorldStatDefinition.values` declared order if available;
  otherwise sorted. The choice doesn't affect correctness; document
  what you picked.
- missing/unknown name → empty string + DEBUG log

## Gotcha

The new regex must not greedily eat the existing Feature 010
tokens. Recommended: run the namespaced pass first, then the
existing un-namespaced pass — neither pattern can match the other's
token shape. Add an assertion in tests that
`{USER:NAME}` and `{INITIAL_MESSAGE}` (or whichever Feature 010
token is real) coexist in the same string and both resolve.
