## Files this step touches

- `backend/app/services/document_editor_system_prompt.py`
- `backend/app/services/world_field_editor_system_prompt.py`
- Their corresponding test modules.

## Reference

Feature 010 introduced these builders and gave them their first
"placeholder list" sections (for runtime placeholders like the
ones it shipped). This step adds a stat sub-list that follows the
same pattern. See
`docs/plans/010.initial_message_placeholders/` for the prior
shape — the rendering chosen there should be reused.

## Reminder

Editor prompts must show the **literal** `{USER:NAME}` text. Under
no circumstances should this step import or call
`apply_runtime_placeholders`. The editor has no chat and no stat
values; substitution is meaningless here.
